# Historial de cambios

## 1.0.0 — 2026-09-08

- Se creó la base modular es-MX para personas adultas.
- Se añadieron reglas de normalización tolerante, abreviaturas, variantes y marcadores de contexto.
- Se incorporó un léxico de expresiones mexicanas con ambigüedad y contraejemplos.
- Se añadieron emociones, estados corporales y necesidades conversacionales.
- Se incorporaron temas psicológicos no diagnósticos y herramientas breves de bajo riesgo.
- Se creó una capa de señales de seguridad independiente, sin score de riesgo.
- Se añadieron ejemplos sintéticos anotados y casos adversariales de evaluación.
- Se registraron fuentes oficiales o primarias y recursos dinámicos con fecha de revisión.
- Se añadió un esquema de interpretación y un validador local.
- Se declaró el paquete como independiente y sin conexión a la aplicación anfitriona.

## Pendiente para 1.1.0

- Revisión por psicología clínica y protocolo de crisis de la institución responsable.
- Revisión con hablantes de distintas regiones, edades y comunidades de México.
- Separación formal de entrenamiento, validación y prueba por familias semánticas.
- Piloto de recuperación léxica con medición de precisión y sobreactivación.
- Directorio por entidad federativa sincronizado con fuente oficial, sin copiar teléfonos vencibles al modelo.
